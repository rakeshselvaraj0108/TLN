Open-source stack & data sources
Globe engine: CesiumJS (Apache-2.0). Orbit propagation: satellite.js (MIT), SGP4/SDP4. Imagery: Esri World Imagery (keyless tile service — Esri, Maxar, Earthstar Geographics and the GIS community). Aircraft: OpenSky Network (CC BY-NC 4.0, live ADS-B — relayed through this deployment's own /api/gods-eye/aircraft so the browser isn't blocked by OpenSky's own CORS policy; the data itself is untouched). Orbital elements: CelesTrak (public two-line elements, fetched directly).
No layer here uses a paid or proprietary feed. Where a real one is needed and this deployment holds no key for it (vessel AIS, public camera feeds), that layer is left empty rather than filled with invented data.
